# Smart Files / Smart Shell (Rust)

Pure Rust file manager + app suite (Files, Photos, Terminal) on egui. Native and WebAssembly from one code base.
No hand-written JS/TS anywhere: the only script in the page is the wasm-bindgen bootstrap, generated by `xtask`.

```
crates/smart-core        backend: Vfs (local, memory, phone), search, jobs, archives (zip + password), devices, audio
crates/smart-ui-egui     UI: design tokens + depth primitives (paint.rs), file manager (chrome/content/overlays/modals),
                         shell.rs (status bar, dock, window manager), terminal.rs, photos.rs, copyfx.rs (transfer animation)
crates/xtask             build tooling in Rust: icons (Solar -> PNG via resvg), synthesised demo audio, wallpapers, bundler
assets/                  generated by `xtask assets` (fonts, icons, audio, wallpapers, thumbs); icon_names.txt drives icons
```

## Build for the web (what `npm run build` serves)
```
sudo apt-get install -y build-essential fonts-inter          # fonts for xtask
curl https://sh.rustup.rs -sSf | sh -s -- -y -t wasm32-unknown-unknown
# wasm-bindgen CLI must match Cargo.lock (0.2.130)
cargo run -p xtask --release -- assets                        # once (needs @iconify-json/solar, see SOLAR_JSON)
cargo build -p smart-ui-egui --lib --target wasm32-unknown-unknown --profile wasm
cargo run -p xtask --release -- bundle                        # writes ../index.html with the wasm embedded
cd .. && npm run build                                        # vite-plugin-singlefile -> dist/index.html
```
Desktop: `cargo run -p smart-ui-egui --release` (`--demo` for the in-memory world).
Deep links (web): `#terminal=ls;neofetch`, `#photos`, `#photo=edit`, `#copy`, `#menu`.
