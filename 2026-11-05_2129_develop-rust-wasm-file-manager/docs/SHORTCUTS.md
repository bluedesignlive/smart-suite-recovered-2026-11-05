# Keyboard shortcuts

`Ctrl` = `Cmd` on macOS. Press **F1** or **?** in the app for the same list.

| Keys | Action | | Keys | Action |
|---|---|---|---|---|
| Ctrl K | Command palette | | Ctrl Shift N | New folder |
| `/` or Ctrl F | Search | | Ctrl Shift C | Copy path |
| Enter / Ctrl O | Open | | Alt ← / → | Back / forward |
| Space | Quick Look (play/pause audio) | | Backspace, Alt ↑ | Enclosing folder |
| Ctrl I | Get Info | | Alt Home | Home folder |
| F2 | Rename | | Ctrl T / Ctrl W | New / close tab |
| Ctrl C / X / V | Copy / cut / paste | | Ctrl Tab (+Shift) | Next / previous tab |
| Ctrl D | Duplicate | | Ctrl N | New window |
| Del | Move to Trash (undoable) | | Ctrl H | Hidden files |
| Shift Del | Delete permanently (asks first) | | Ctrl \ | Toggle sidebar |
| **Ctrl Z** | **Undo** trash / copy / rename | | G / L | Grid / list |
| Ctrl A | Select all | | Ctrl + / − | Thumbnail size |
| Ctrl Shift I | Invert selection | | F11 | Fullscreen |
| Home / End | First / last item (+Shift extends) | | F5 | Refresh |
| PageUp / PageDown | Move a page | | D | Light / dark |
| Arrows (+Shift) | Move / extend selection | | Esc | Close / clear |
| Type any letter | Jump into search | | Ctrl Q | Quit |
