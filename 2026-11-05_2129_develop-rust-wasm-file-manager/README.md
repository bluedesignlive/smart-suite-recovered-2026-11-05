# Smart Files

A fast, fault-tolerant file manager written in **100 % Rust** — one code base, two targets:

| Target | Output | Notes |
|---|---|---|
| Linux (Wayland + X11) | `Smart_Files-<ver>-x86_64.AppImage` | tested design target: Wayfire, GNOME on X11 |
| WebAssembly | one self-contained `index.html` | in-memory demo world (browsers have no file system) |
| Windows / macOS / FreeBSD | `cargo build --release` | same source; packaging scripts land in a later pass |

No hand-written JavaScript or TypeScript anywhere. The only script in the HTML page is the standard
wasm-bindgen bootstrap, **generated by `xtask`** (Rust). `package.json`/`vite.config.ts` exist only so the
sandbox's `npm run build` can serve the generated page.

```
crates/smart-core        backend: Vfs (local, memory, phone), search, jobs, archives, devices/mounts, trash, audio
crates/smart-ui-egui     UI: design tokens + depth primitives, file manager, shell, terminal, photos
crates/xtask             build tooling in Rust: icons (Solar → PNG), audio, wallpapers, wasm bundler
packaging/               AppRun (fallback chain), .desktop, metainfo
tools/build_appimage.sh  builds the AppImage
docs/                    ARCHITECTURE · TOOLKIT-DECISION · SHORTCUTS · PACKAGING · SAFETY
```

## Run

```sh
# the AppImage (needs libfuse2 on the host, or run with --appimage-extract-and-run)
chmod +x Smart_Files-*.AppImage && ./Smart_Files-*.AppImage            # opens your real files
./Smart_Files-*.AppImage ~/Pictures                                    # open a folder
./Smart_Files-*.AppImage --demo                                        # sample world, touches nothing
./Smart_Files-*.AppImage --help
```

From source: `cargo run --release -p smart-ui-egui` (Linux needs `libxkbcommon-dev libwayland-dev libasound2-dev pkg-config`).

## What it does with your real system

* **Browse** any folder, tabs, grid / list, sort, hidden files, live refresh via inotify (`notify`).
* **Open** files with your real apps (`xdg-open`, `.desktop` entries, *Open With…*, set default).
* **Images** get real thumbnails (decoded off the UI thread, cached) and a Quick Look viewer.
* **Copy / move / duplicate** run as cancellable background jobs with progress, name-conflict handling and cross-device support.
* **Delete is safe by default**: *Del* goes to the Trash and offers **Undo**; *Shift Del* asks for confirmation. Copies and renames are undoable too (**Ctrl Z**).
* **Drives**: removable volumes are listed and can be mounted / unmounted / ejected (`udisksctl`, falling back to `gio`/`umount`); phones over ADB; network shares through GVfs.
* Archives (zip incl. passwords), search (fuzzy, content, duplicates, large/old files), tags, command palette (**Ctrl K**), terminal and photo app.

## Build everything

```sh
sudo apt-get install -y build-essential pkg-config libxkbcommon-dev libwayland-dev libasound2-dev fonts-inter
curl https://sh.rustup.rs -sSf | sh -s -- -y -t wasm32-unknown-unknown
cargo install wasm-bindgen-cli --version 0.2.130            # must match Cargo.lock
npm i --prefix /tmp/ic @iconify-json/solar                  # icon *data* only (SVG paths), no JS is used

cargo run -p xtask --release -- assets                      # icons, fonts, audio, wallpapers  (once)
cargo build -p smart-ui-egui --lib --target wasm32-unknown-unknown --profile wasm
cargo run -p xtask --release -- bundle                      # → ./index.html with the wasm embedded
npm run build                                               # sandbox preview → dist/index.html

tools/build_appimage.sh                                     # → dist-appimage/Smart_Files-0.1.0-x86_64.AppImage
```
