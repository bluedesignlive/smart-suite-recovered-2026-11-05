# Smart Desktop

A portable, premium desktop environment written in Rust (egui renderer, WebAssembly in the browser, native on desktop).
No hand-written JS/TS anywhere: the only script in the page is the wasm-bindgen bootstrap, generated by `xtask`.

```
smart-desktop/
├── apps/                    the frontends to the OS — they know nothing about compositing
│   ├── files/               file manager (+ system file picker for the desktop, transfer scenes)
│   ├── photos/              library, viewer, filmstrip, editor
│   ├── terminal/            smart-shell terminal (blocks, vt100 full-screen apps, agent hand-off)
│   ├── capture/             screenshot (screen / window / region), screen video, audio-only
│   ├── settings/            native settings for the desktop environment itself
│   └── assistant/           assistant bar, per-window orbs, AI mode, Studio (generated apps)
├── crates/
│   ├── smart-core/          backend: VFS (local / memory / phone), search, jobs, archives, devices
│   ├── smart-desktop/       the desktop crate
│   │   └── src/
│   │       ├── ui/          smart-ui: tokens, depth primitives, widgets, sound suite, app kit
│   │       └── shell/       window manager + compositor: scene graph, snapping, dock, status bar,
│   │                        desktop surface, notifications, dialogs, boot, assistant engine
│   └── xtask/               build tooling in Rust: icons, wallpapers, bundler
├── protocol/                the Smart Protocol contracts this shell implements (subset vendored)
│   └── schema/              compositor, clipboard, capture, audio, ai, files, app, display, input, clock
└── assets/                  fonts (Inter + JetBrains Mono), icons, tokens
```

## Shell architecture

* **Scene graph.** Every window is a node with spring-animated geometry and a depth (z → shadow). Drag, snap, tile,
  cascade, split and AI relayouts all move nodes, so you watch the scene rearrange itself.
* **Snapping.** Drag a title bar to an edge (half), a corner (quarter) or the top (maximise); a ghost shows the target.
* **Dock.** Magnification, auto-hide, size, live window previews on hover, an assistant orb and the Void (trash).
* **Status bar.** A live "island" (link latency, transfers, recording, the assistant), clipboard history, volume wheel,
  battery and clock; menus collapse before they can overlap.
* **Desktop.** Draggable icons backed by `~/Desktop`, OS drag-and-drop, context menus, a wallpaper dialog for images and
  video, compact dialogs, notifications (optionally read aloud) and a boot sequence.
* **Assistant.** One engine for every app: live state in the prompt, global memory, tools (open/close/arrange/snap windows,
  theme, wallpaper, dock, volume, terminal, screenshots, generate apps). Providers are OpenAI-compatible: OpenRouter,
  NVIDIA NIM, OpenAI-style gateways, Ollama, or the on-device intent engine with no key.
* **Sound.** Every sound is synthesised in Rust (one glassy-bell timbre in D-major pentatonic).

## Smart Protocol

`protocol/` holds the capability schemas from `smart-foundation/smart-protocol-official` that this shell speaks:
`compositor.capnp` (scene, surfaces), `clipboard.capnp`, `capture.capnp`, `audio.capnp`, `ai.capnp`, `files.capnp`,
`app.capnp`, `display.capnp`, `input.capnp`, `clock.capnp`. The shell's window manager, clipboard history, capture app,
sound suite and assistant are written so each can be swapped for another implementation of the same contract.

## Build for the web (what `npm run build` serves)

```
curl https://sh.rustup.rs -sSf | sh -s -- -y -t wasm32-unknown-unknown
# wasm-bindgen CLI must match Cargo.lock (0.2.130)
cargo run -p xtask --release -- assets                         # fonts, icons, wallpapers, audio (once)
cargo build -p smart-desktop --lib --target wasm32-unknown-unknown --profile wasm
cargo run -p xtask --release -- bundle                         # writes ../index.html with the wasm embedded
cd .. && npm run build                                         # vite-plugin-singlefile -> dist/index.html
```

Desktop: `cargo run -p smart-desktop --release --bin smart-desktop-bin` (`--demo` for the in-memory world).

Demo files in Documents: a 5 GB reel, a 20 GB raw footage file (15 s paced copy) and a 5 GB zip (10 s extraction scene).
